# Blog Preview Card

A responsive **blog preview card** built with HTML and CSS as part of a [Frontend Mentor](https://www.frontendmentor.io/) challenge.

The goal of this project was to recreate the provided design as accurately as possible while practicing responsive layouts, typography, spacing, and clean HTML/CSS structure.

## 🔗 Live Demo

[View the live website](https://greg-hooper-blog.netlify.app/)

## 🛠️ Built With

* HTML5
* CSS3
* Flexbox
* Responsive design
* Local fonts
* Semantic HTML

## ✨ Features

* Responsive blog preview card
* Clean and minimal design
* Local font loading
* Article category and publication date
* Article title and description
* Author information and avatar
* Hover and focus states
* Responsive sizing across different screen sizes

## 📚 What I Learned

This challenge helped me practice turning a visual design into a structured HTML and CSS implementation.

Some of the main things I practiced were:

* Creating a semantic HTML structure
* Using Flexbox for layout and alignment
* Working with responsive sizing
* Loading and using local fonts
* Managing spacing and typography
* Creating borders and shadows to match a reference design
* Adding interactive states to links
* Paying closer attention to small visual details

## 🧩 Challenges

The main challenge was matching the **spacing and proportions** of the card to the original design.

Although the component looks simple, small differences in padding, font size, line height, image dimensions, borders, and shadows can noticeably change the final result.

I worked through this by breaking the design into smaller parts and adjusting the CSS properties individually while checking the overall result against the reference design.

## ♿ Accessibility

The project uses semantic HTML where appropriate, descriptive alternative text for images, and real links for interactive elements.

Accessibility is something I want to continue improving as I build more projects.
